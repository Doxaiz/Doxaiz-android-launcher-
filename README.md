# Doxaiz launcher

Лаунчер для Android (`com.doxaiz.launcher`), версия 5.7-test. Русский интерфейс, рабочий стол, каталог приложений, пользовательская шторка и резервное копирование.

**Статус:** тестовая версия. Проверено в CI на эмуляторе Android 14 (API 34): сборка, установка, роль HOME, отрисовка рабочего стола и каталога, отсутствие падений. Плавность и аппаратные функции на реальном телефоне не измерялись — эмулятор рисует программно, его метрики кадров для этого непригодны. Светлая тема не завершена: шторка остаётся тёмной. Пользовательские резервные копии JSON не шифруются и могут содержать сведения о скрытых приложениях.

## Сборка

Проект собирается штатным Gradle: `./gradlew assembleDebug` (Android SDK Platform 34, AGP 8.2.2, Gradle wrapper 8.7, JDK 17). Для проверки правил R8: `./gradlew assembleRelease`. Приложение не запрашивает разрешение INTERNET; сеть нужна только для загрузки инструментов сборки.

Для сборки подписанного APK через `build.sh` требуются JDK, Android SDK Platform 34 и Build Tools 34 (скрипт ожидает их в `platforms/android-34` и `build-tools/android-14` внутри `ANDROID_SDK_ROOT`), bash и zip. Передайте путь к приватному хранилищу ключей через `DOXAIZ_KEYSTORE`, пароль хранилища через `DOXAIZ_KEYSTORE_PASSWORD`, пароль ключа через `DOXAIZ_KEY_PASSWORD`, при необходимости алиас через `DOXAIZ_KEY_ALIAS` (по умолчанию `doxaiz`). Затем выполните `bash build.sh`. Скрипт не генерирует ключ и не содержит пароль.

**Не публикуйте хранилище ключей и пароли.** Для обновления уже установленного APK необходим совместимый ключ подписи; APK, подписанный новым независимым ключом, не установится как обычное обновление. Сохраните оригинальный ключ отдельно. Debug APK использует другую подпись и тоже не обновит установленную release-версию.

## Обои

Встроенное изображение — сгенерированная композиция по мотивам Kurumi и Xiao Bai, не официальный кадр. Права на персонажей принадлежат их правообладателям; перед публичным распространением изображение следует проверить на соответствие применимым правам.

## Проверка

`./gradlew test` запускает JVM-проверки из `tests/` (расчёты, валидация, кривая перелистывания). Они не заменяют проверку UI, аппаратных возможностей и службы специальных возможностей на реальном устройстве.

Android Lint входит в CI с порогом «ошибки валят сборку» (0 ошибок на 5.7-test). Отчёт — `AUDIT.md` §13.

GitHub Actions (`.github/workflows/ci.yml`) дополнительно собирает APK и запускает его на эмуляторе Android 14: установка, назначение HOME, дамп дерева интерфейса, открытие каталога, прокрутка, `dumpsys gfxinfo`, поиск падений именно `com.doxaiz.launcher`. Debug-APK подписывается одноразовым debug-ключом CI — он не подходит для обновления установленной release-версии.

Отчёт по аудиту и журнал правок — в [AUDIT.md](AUDIT.md).
